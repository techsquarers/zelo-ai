# Tech EdTech Pro (zelo-ai)

> Personalized learning platform that turns career goals into daily execution — with roadmaps, tasks, XP, levels, and streaks.

A modern EdTech backend + frontend that helps users build technical skills consistently through structured roadmaps and gamified daily plans.

---

## Features

- **Authentication** – Email/password signup & login (JWT)
- **User Profiles** – Personal info + target role
- **Smart Roadmaps** – Role-based multi-phase learning paths (stored as structured JSON)
- **Daily Plans & Tasks** – Actionable daily tasks with estimated time, resource links, and XP rewards
- **Gamification**
  - Experience Points (XP) & Levels
  - Daily Streaks (with streak freezes)
- **Progress Tracking** – Monitor completion across roadmap phases and daily plans

---

## Tech Stack

### Backend
- **FastAPI** (Python 3.13+)
- SQLAlchemy (async) + Alembic
- PostgreSQL
- JWT Authentication
- Pydantic Settings

### Frontend
- React 19 + Vite
- (Tailwind CSS + modern UI planned)
